SOBOLTECH — GOTOWA STRONA-KATALOG

1. Uruchomienie lokalne:
   - rozpakuj folder,
   - otwórz index.html w przeglądarce.

2. Dodawanie ofert:
   - otwórz plik products.js w Notatniku / Notepad++ / VS Code,
   - skopiuj jeden blok produktu,
   - zmień title, category, platform, price, image, description i url,
   - zapisz plik i odśwież stronę.

3. Hosting:
   Strona jest statyczna, więc możesz ją wrzucić m.in. na GitHub Pages, Netlify, Cloudflare Pages, Vercel albo zwykły hosting WWW.

4. Domena:
   Po zakupie domeny można podpiąć ją do hostingu, np. soboltech.pl / sobol-serwis.pl / sobolparts.pl.

5. Ważne:
   - nie używaj logotypów OLX / Allegro / Vinted bez upewnienia się co do zasad ich użycia,
   - jeśli dodasz formularz, analitykę, newsletter, reklamy lub marketingowe cookies, zaktualizuj politykę prywatności i mechanizmy zgód,
   - jeśli sprzedaż ma charakter zorganizowany i zarobkowy, sprawdź obowiązki dla działalności nierejestrowanej/JDG.
